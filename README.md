# golden-recipe-lab

Digital Wallet / Verification Credential (VC) system for Laboratory Data Provenance.

## Problem

Lab data recorded manually or in Excel cannot be proven to be correct, complete, and unaltered, making experiments unreliable and non-reproducible.

## Solution

A digital wallet system that captures experiment data with cryptographic verification:
- QR-based reagent lot tracking
- Timestamped experiment records
- Immutable audit trail
- Verification credentials for data integrity
